## 论文与实现的对应

- §4.1：`stroke.resample_2d` 等距采样，`prepare` 发射创作相机射线并分为 on/off；深度突变时增加中间射线检测。
- §4.2：off 序列采用该序列所有射线到几何的最近距离的最大值；on 的高度在实际 off 邻居之间插值。深度不连续切分不会把高度重置为零。height 指离物距离。
- §4.2.1：`candidate_vertices` 获取偏移实体并集的前后等值面交点，按深度排序；中间冗余背面候选默认剪枝，数据保留并可恢复。
- §5.1：`build_segments` 检查深度、距离梯度和连接穿入，提取最长 on 路径，作为段图节点。
- §5.2：`interpolate` 按射线深度线性插值；单尖角时使用论文式 (1)；`outer` 按最多四个 on 顶点的深度变化外推首尾 off 段。
- §5.3：在深度切分附近生成裁剪后的 on 段，加入 off 桥接，所有桥接都做穿入检查。
- §6.1：三点离散曲率及曲率总变差为代价；off 代价包含连接边界邻域；通过拓扑松弛求最优路径。skip 将候选轨道锁定后重新搜索，复用已有候选与边代价。
- §6.2：三维等距重采样后，保留 height 和创作射线的对应；使用一阶/二阶内部能量及投影/高度外部能量，以解析梯度、正定预条件器和回溯步长下降。高度通过软能量惩罚保持，不再使用高度带或强制高度投影；普通开放曲线的首尾点参与优化。显示曲线为经过穿入检查的均匀 Catmull–Rom；若样条无效则显示已验证折线并在诊断中注明。
- §6.3：局部重画以原区间端点作为固定候选进入推断，平滑时继续固定端点；引导物使用相同几何接口；已有曲线不会因移除引导物而被删除。

## 重要工程约定与差异

1. 使用简单几何的精确外部欧氏距离查询，替代论文深度 7 八叉树。盒体支持三轴尺寸、刚体旋转；球体和正四面体使用半径、刚体旋转。四面体顶点与 Three.js TetrahedronGeometry 的约定一致。2026-11-04 新增通用三角网格，使用 BVH 加速最近距离和射线求交；支持非凸与多个不连通实体的深度候选。实体并集外部距离正确；内部最小 signed-distance 只用作内外与穿入判定，不宣称是重叠并集内部的精确欧氏距离。
2. 世界坐标为右手系、Y 向上，相机沿局部 -Z 观察；相机 world/projection 数组按列主序传输。场景按包围范围归一化，结果反变换到原世界坐标。CSS 像素用于笔触与相机 viewport。
3. 基础二维采样等距。检测到可见棱边的连接折线穿入时，局部增加射线，最多六轮且受采样预算约束。这是针对盒体/四面体的数值补充。
4. 未公开的连接阈值配置化：归一化相机深度差默认 0.25，梯度余弦阈值默认 -0.5，以覆盖四面体面法线转折并拒绝相反侧连接。没有使用 beam search 隐式删去分支；超预算直接报错。
5. 深度桥接裁剪窗口默认最多 16 个样本，为有限计算预算下的工程约定。闭合输入合并屏幕端点，并计入首尾邻域代价；三维端点接近容差为归一化 0.025。
6. 论文式 (6) 印刷的绝对点积项与最小化投影偏差的文字目标冲突。这里用 `1-dot(ray, sketch_ray)`，权重按原数值之和归一化；该修正不是作者勘误。
7. 2026-11-02 按用户确认移除原先新增的 ±0.003 归一化高度带、深度区间缓存及高度硬裁剪；保留公式 (6) 对应的高度误差软能量和 §4.2.1 的候选点等值面求交。普通绘制的开放端点可调整，只有局部重画通过 `fixed_endpoints=True` 固定连接端点。仍保留创作射线投影和数值穿入检查，这些是当前工程约束；不能宣称完全等同论文的纯软能量优化。高度误差现在是能量权衡的实际结果，不再保证处于旧高度带内。
8. 线段与最终样条采用最大归一化步长 0.003 的数值检查，允许默认 0.0005 的穿入容差。表面接触与有限精度下微小负值可出现。这不是连续曲线严格无碰撞证明，也不保证有半径的管体净空。
9. 绘制中以笔触前缀限频重新求解，响应有 request ID 与 scene revision 防止旧结果覆盖。提供双向 WebSocket 接口并合并待处理前缀；默认界面使用 HTTP 前缀预览。没有声称实现原 C++ 程序同样的 GPU 或全部增量数据结构。
10. 首个 on 段默认在可见侧，用户可明确 skip 覆盖。全 off、空场景、不可行深度锁定、图预算耗尽均明确返回。局部重画的诊断指标只针对替换段；旧段有自己的创作相机，不能用新相机的投影误差评价全曲线。

## 验证

自动检查覆盖相机往返、三种几何体的表面/偏移交点、并集隐藏交点、height 插值、DAG 对穷举、尖角插值、能量解析梯度对有限差分、六种固定场景、skip 实际深度变化、闭合、换视角固定端点重画、引导物移除、退化输入、预算状态、API 输入校验与版本回传、WebSocket 回传。软高度版本另检查三种 U 形笔触在 0 / 80 次迭代下不出现首尾折返、普通端点可调整，以及高度误差仍影响能量与梯度。

性能报告位于 `backend/benchmark.json`，包含 Python 和 CPU 信息、首次耗时、5 次热缓存测量的 P95、采样数量、投影与高度误差。5 次测量只用于本机工程反馈，不是统计意义上的论文性能复现；首次值为单次测量。最终报告应以该 JSON 为准，避免复制过时数字。

浏览器检查覆盖固定球体求解、前后候选切换、旋转检查遮挡、双长方体桥接以及实际诊断面板。前端通过 `npm run build` 的 TypeScript 与生产构建检查。

2026-11-02 软高度版本基准：七个案例全部返回有效结果；首次单次约 18—250 ms，5 次热缓存求解 P95 约 9—167 ms。其中 10 个球体 / 200 个采样点的案例为首次约 173 ms、热缓存 P95 约 66 ms。上述数字是纯求解时间，使用 24 次平滑预算；不包含浏览器、网络、序列化和首次模块导入。投影 P95 最大约 0.1204 px；高度误差 P95 最大约 0.1255 归一化单位。高度误差不再被旧硬高度带压低。具体原始数据以 `backend/benchmark.json` 为准，更新前报告备份在 `.skippy-backup/soft-height-20261102/backend/benchmark.json`。

浏览器中另通过真实拖动生成第二条新曲线，返回投影 P95 小于 0.01 px；验证使用实时页面与 Python API，而非预先渲染结果。界面截图见 `docs/skippy-preview.png`。

## 仍保留的边界

- 不含八叉树距离场、生成曲线作为后续支撑几何、相机姿态或速度规划、视频生成及 VR/AR。
- 部分输入本身没有可行连续解；当前系统返回无解而不是强行穿物生成。
- 渲染为浏览器线条，中心线精度与管径碰撞是不同问题。
- 第一版 JSON 文件保存供本地复现，不包含账号或服务端数据库。
- 当前本地版本尚未发布到 Sites；线上 Python API 托管位置待之后确定。

## 2026-11-04 网格导入扩展

前端支持本地 ASCII / 二进制 PLY 面网格和自包含 GLB；GLB 节点、网格实例和静态姿态的变换会烘焙为求解用三角面。模型自动居中并等比缩放到最长边 3 个工作单位。顶点颜色和基础材质颜色保留，纹理、动画与压缩扩展暂不支持。单个模型限制为 64 MiB、10 万顶点和 10 万三角面。纯点云没有可查询表面，导入时明确提示先重建网格。

`mesh.py` 将最近三角面距离、正射线距离、封闭流形内外判定和欧氏偏移交点接入 `Scene`。三角面的偏移由面棱柱、边胶囊和端点球组成，合并射线区间后保留所有可见/背面候选；多实体部件按并集处理，避免使用整个模型的凸包或包围盒。开放/非流形部分按无内部的双面表面查询，不承诺实体穿入语义；自交网格和独立嵌套壳体空腔需要预处理。原有软高度平滑模块没有因本次扩展改动。

新增自动检查覆盖 PLY 的两种编码、GLB 多节点变换与镜像绕序、保存数据的网格校验、网格与解析盒体距离/交点对照、BVH 对穷举、多部件并集、非均匀变换、开放表面、正射线距离，以及网格上的 on/off 推断、skip、局部重画与 HTTP 校验。另通过正在运行的 Vite 代理和 Python API，实际解析两种 PLY 及多部件 GLB 后生成三维曲线。真实浏览器鼠标验收因浏览器控制授权超时未完成，不能将上述接口联调当作浏览器操作已通过。

## 2026-11-04 控制台进度扩展

HTTP / WebSocket 服务和离线 CLI 默认输出分阶段控制台进度，使用 `ContextVar` 隔离每个请求。数量已知的阶段按实际工作项计数，未知总量的路径提取显示探索数量；平滑阶段记录有效迭代、回溯、能量与停止原因。输出到 stderr，独立算法调用默认静默，CLI 的 stdout 仍为 JSON。支持 `SKIPPY_PROGRESS` 和 `SKIPPY_PROGRESS_INTERVAL` 环境变量。

后续按用户反馈改为 `tqdm` 原位显示：所有请求共用一条活动进度栏，最新请求优先，阶段变化和中间更新复用该行，整个请求只保留一条最终结果；非交互式输出只保留最终摘要。使用 `logging_redirect_tqdm` 协调 Uvicorn 的标准日志，并根据中文字符显示宽度裁剪标题以防自动换行。新增依赖 `tqdm`，提供 `SKIPPY_PROGRESS_MODE=auto/inline/plain` 控制显示方式。检查覆盖大量更新只有一条最终记录、多线程请求、标准日志插入、窄终端中文显示、重定向输出和数值结果一致。

本次仅在现有几何、推断和平滑计算周围加入观测信息，保留用户已有的内部 / 外部能量分项修改。进度输出会占用少量运行时间，控制台开启时的墙钟计时会包含输出开销，不能直接与先前关闭日志的基准耗时比较。检查覆盖真实处理计数、提前终止、零迭代、缓存复用、并发请求隔离、失败进度、控制台断连、CLI 输出流，以及启用前后曲线坐标和能量轨迹一致。
